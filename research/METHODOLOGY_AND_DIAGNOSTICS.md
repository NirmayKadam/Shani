# Methodology and Diagnostics

> Companion to `paper/main.tex`. This file explains **what was wrong, what was changed, and how each result is produced**.
> It deliberately quotes no results: every number is generated by `python research/reproduce_all.py`
> into `output/paper/numbers.tex`, `output/paper/tables/` and `output/phase0_diagnostics/`.
> Earlier versions of this document claimed the edge "survived" closed-form pricing; that interpretation was wrong (see §2).

## 2. What was wrong (and why the old interpretation failed)

1. **Grid error was the call signal.** The Crank-Nicolson price differs from closed-form Black-Scholes at the same volatility; the call mispricing is almost perfectly rank-correlated with that difference (Phase 0, `GridSpearman`).
2. **The put signal was a carry error.** Pricing off spot with q = 0 ignores the forward basis. The ATM put "mispricing" equals the zero-dividend parity residual. Every headline trade was a put. Closed-form pricing alone (+`ClosedFormReturn`%) therefore did **not** show a genuine edge — the remaining profit came from this bias, and it disappears with forward-consistent pricing (waterfall row S2).
3. **With consistent pricing, calls carry no signal.** The spline interpolates call IVs, so Black-76 reproduces every call price; the only residual is the put's deviation from parity with the calls, i.e. non-synchronous closing-price noise.
4. **Same-bar fills.** Signals at a close were filled at that close.
5. **Wrong-contract marking.** The legacy panel holds one expiry per day and rolls weekly; positions were looked up by (date, strike) only, so on roll days they were re-marked against the next weekly (large artificial jumps, spurious take-profits). A strike leaving the panel's window was marked at its entry price with zero mispricing, forcing an exit at cost.
6. **Accounting.** Exit-only equity hid drawdowns. In the stress test the equity curve charged 1× costs while the return used the multiplied costs, so Sharpe/drawdown did not move.
7. **Price field and stale prices.** Some legacy prices were SETTLE rather than CLOSE; zero-volume CLOSEs (stale carried-forward prices) were treated as tradeable. On far expiries stale CLOSEs corrupt the IV inversion.
8. **STT** used the post-April-2023 rate throughout.
9. **Documented rules differed from the code.** The Retail rule in the code is `(RSI > 50 or RSI ≤ 45) & MACD hist > 0` for calls and `(RSI < 50 or RSI ≥ 55) & MACD hist < 0` for puts; the paper now states this. A later runner had loosened the Hybrid RSI bands; they are restored to the frozen < 65 / > 35.

## 3. What the corrected pipeline does

- **Pricing / signal** (unchanged definition): Black-76 with a forward from ATM put-call parity, IV inverted from CLOSE, natural cubic spline across strikes, mispricing = market − fair. In v2 only contracts that traded feed the forward and the IVs.
- **Expiry**: signals on the nearest expiry with ≥ 14 DTE; mispricing computed for all expiries 2–45 DTE so held contracts keep their own signal.
- **Fills**: next session's close, on the signal's own (expiry, strike, type), only if that contract traded, never on its last session before expiry.
- **Marks**: daily, on the position's own contract; a zero-volume day carries the last mark.
- **Exits**: 35% stop, 60% target, mean reversion (|δ| < ε/2 after ≥ 2 bars), 5 sessions, pre-expiry square-off.
- **Costs**: STT by date on the sell leg; exchange, stamp, SEBI, GST, ₹20/order, 0.5% half-spread per leg. Equity books each trade's own costs (half at entry, half at exit).
- **Sharpe**: RBI repo-rate step function as the hurdle; idle cash earns nothing.
- **Evaluation**: each period is an independent backtest from ₹1 lakh. Reported per cell: return, return without the largest |P&L| trade, mean/median net return on premium with a 10,000-resample bootstrap 95% CI, win rate, profit factor, Sharpe, max drawdown, and the percentile against a puts-only random baseline (same fills/exits/costs, entry rate calibrated to the strategy's trade count, 500 draws).
- **Signal test** (`analysis/signal_test.py`): for each near-ATM put on the signal expiry, delta-hedged next-bar P&L `h = ΔP − Δ_F·ΔF` with `F = S·e^{rT}` from the index close, at two horizons (signal close → next close; next close → following close), compared with the all-puts mean and the round-trip cost; date-clustered bootstrap CIs.

## 4. Correction waterfall (`analysis/waterfall.py`)

On the original 180 sessions, cumulatively: S0 original → S1 closed-form → S2 forward-consistent Black-76 on CLOSE → S3 next-bar fill → S4 contract lock → S5 no stale prices + daily MTM → S6 full-chain data. S0–S1 run the original `backtest/strategies.py`; S2 onward run `RobustBacktestStrategy` with legacy switches, and the S2 trades are checked to be identical under both code paths (`manifest.json → waterfall_bridge_check`).

## 5. Not changed, deliberately

Stops, κ, the 150-point window, 50-unit sizing and the strike choice (first qualifying strike in ascending order) were frozen before the 3.5-year test and were not tuned afterwards. Changing any of them should be run as a separate variant applied to all strategies.
